# 画布工作室 v3.6.4 · 多画布与双视图

画布工作室面向广告、MV、短片、产品视频、漫剧、电影、电商、设计与视频创作者，是一套通用的智能视觉创作画布。v3.6.2 将单个视频节点升级为非破坏式视频工作室；项目级多轨剪辑留给后续的主时间线阶段。


## v3.6.4 · 多画布工作区

- 左上角工作区内不再只有一张画布。当前画布名称可以展开画布菜单，支持 **新增、切换、重命名、复制、删除**。
- 工作区名称与画布名称分离；一个工作区可承载多张独立画布。
- 删除当前画布后会自动切换到剩余画布；当只剩最后一张画布时禁止删除，避免工作区进入无画布状态。
- 「在新窗口打开」会通过 `?projectId=` 打开指定画布，便于并行查看。
- 画布切换会先保存当前画布，再加载目标画布的完整节点、连线、分组、状态和视图设置。

## 工作流 / 故事版双视图

左上角两个视图按钮现在是真实功能，不是装饰按钮：

- **工作流视图**：保留无限节点画布。用于查看与修改文本、图片、视频、音频、脚本节点之间的依赖关系；现有分组、保存为工作流、我的工具箱、整组执行、批量连接等能力全部保留。
- **故事版视图**：按镜头组织生产素材。每个镜头横向展示 **脚本/提示词/参考 → 分镜图 → 视频 → 音频**，适合逐镜头检查与生产。
- 可以从当前画布的图片创建故事版，也可以从脚本或选中图片进入已有故事版设计能力。
- 故事版支持镜头顺序调整；顺序写回故事版 `frameOrder` 并同步分组布局，而不是仅改变界面显示顺序。
- 单镜头可以定位回工作流、编辑镜头设计、生成/重生成分镜图、创建视频节点、生成/重生成视频。
- 故事版顶部支持补齐视频节点和生成故事版视频；生成仍复用现有节点和生成逻辑。
- 图片/视频继续使用全局媒体预览增强，点击即可放大查看。

## v3.6 核心能力

- 专业视频播放器：播放/暂停、逐帧、J/K/L 快捷控制、倍速、循环与时间码。
- 帧时间线与入点/出点区间。
- 片段裁剪与精确抽帧。
- 向前/向后延长与局部重拍。
- 视频版本树；工作版本与画布已应用版本相互独立。
- 同步版本对比。
- 应用到节点、发送版本、创建分支。

## v3.6.2 高级能力

- **智能重构图**：支持 9:16、4:5、1:1、16:9、21:9；本地媒体使用 FFmpeg 真实裁切并保留音频。当前“自动”模式采用焦点与连续性启发式，不冒充逐帧语义主体跟踪。
- **变速**：0.5×–2× 非破坏变速，支持保持音高。
- **画面定格**：在指定时间点插入冻结画面与等长静音；保持源帧率，并根据 FFprobe 返回实际输出时长。
- **音视频分离**：真实分离为无声视频与独立音频节点。
- **审片标记**：持久标记、M 快捷打点、时间线跳转，以及“标记 → ±0.6 秒局部重拍区间”。
- 切换视频工作室工具时会恢复已保存的播放头位置，不会被新视频元素重置为 0。

## v3.6.2 最终质量验证基线

使用同一段 6.000 秒 / 640×360 / 30 帧每秒 / AAC 测试视频：

- 智能重构图 9:16：202×360，输出 6.016 秒，音轨保留。
- 1.5× 变速：输出 4.014 秒，音轨保留。
- 2.000 秒处定格 1.500 秒：输出 7.516 秒，640×360 / 30 帧每秒，音轨保留。
- 音视频分离：无声 MP4 6.000 秒 + 独立音频 6.016 秒。
- 2.400 秒审片标记 → 重拍区间：1.800–3.000 秒，问题描述自动写入重拍提示词。
- 应用 / 发送 / 分支：兼容通过。
- Playwright 界面验证：0 个页面错误 / 0 个控制台错误。
- Node HTTP 服务：200 正常。

AAC/MP4 容器可能带来十几毫秒级时间基差异，质量验证按 ±50 毫秒容差验收。

## 安全交付

正式源码包不包含 `.data/`、SQLite/WAL/SHM、供应商配置、密钥/令牌、测试媒体、日志、`node_modules` 或本地备份文件。运行时数据会在启动后按需重新生成。

## v3.6.3 · 标准异步视频协议

- 新增供应商级 `标准异步视频协议 v1`，视频模型不再要求逐模型填写创建接口。
- 固定创建端点：`POST /v1/video/generations`，鉴权继承供应商 `Authorization: Bearer <API_KEY>` 配置。
- 请求体原生发送 `model / prompt / duration / ratio`，并允许额外供应商参数透传。
- 创建任务 ID 支持自动识别 `id / task_id / data.id / video_task_*`。
- 默认轮询 `/v1/video/generations/{{taskId}}`；查询接口、状态字段、结果字段可在供应商级高级设置一次配置，所有视频模型继承。
- 模型级 `generic-async` 保留为未知协议/特殊模型的手动覆盖与兜底。
