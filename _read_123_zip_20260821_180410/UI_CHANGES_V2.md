# UI Polish v2

本轮只做以下 4 项界面与媒体预览增强：

1. 顶部工具栏、底部 Dock、左侧工具栏统一为功能语义明确的线性 SVG 图标。
2. 全站字体统一为同一字体栈和标准字号阶梯，整体较旧版提升一档；模型管理页同步生效。
3. 文本 / 图片 / 视频 / 音频 / 脚本节点详情框统一为新的深色专业创作工具样式：详情标题、类型徽标、放大的 Prompt 区、分区标签、模型与参数网格、统一控件尺寸和状态。
4. 所有画布节点与工作台/质检/版本对比等界面中的真实图片、视频结果增加放大入口；图片本身也可直接点击放大。视频保留播放控制，并通过右上角放大按钮进入大图/大视频预览。支持 Esc、点击背景、关闭按钮退出。

核心生成与业务逻辑文件未修改：app.js / server.js / store.js / models.js / three-runtime.js / ui-zh.js。
